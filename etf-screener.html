算法说明 · 三维周期状态机与 FitScore 评分口径

① 股债性价比 ERP

ERP = 100 / 沪深300 PE(TTM) − 10Y 国债收益率
≥ 5.2% 极高赔率击球区；3.8% ~ 5.2% 合理区间；3.2% ~ 3.8% 中性偏贵；≤ 3.2% 高估预警区。

② 均线动量趋势得分（−100 ~ +100）

收盘价相对 MA20 / MA60 / MA250 的偏离度（权重 25% / 25% / 20%，分别以 ±5% / ±8% / ±15% 封顶）+ 近 20 / 60 日涨跌幅（各 15%，以 ±8% / ±15% 封顶）。

③ 四阶段判定优先级

PE 分位 ≥ 75 或 ERP ≤ 3.2 → 避险期；否则趋势 > 15 → 主升期；趋势 < −20 → 破位避险；ERP ≥ 5.2 或 PE 分位 ≤ 25 → 底部布局期；其余 → 震荡防御期。

④ 当期环境契合度 FitScore

0.35×周期类别契合 + 0.25×估值安全垫与股息 + 0.20×低费率与规模流动性 + 0.20×夏普与抗回撤
周期类别契合按 ETF 风格（核心宽基 / 成长宽基 / 红利 / 景气行业 / 港股 / 美股 / 黄金 / 长债 …）与当前周期查表；估值分 = 0.45×(100−PE分位) + 0.25×(100−PB分位) + 0.30×股息率(6%封顶)。

⑤ 三级跨设备数据加载

HTTP(S)：fetch ./data/etf_latest.json 获取最新数据；本地 file://：同步加载 ./data/etf_latest.js；单文件分享：回退页面内置快照，并支持手动导入 JSON。
